fastframe 0.17.0 tells an app when each release came out, so an app can decide which release someone may have from its own rules, such as how long their licence includes updates.

Move every fastframe crate to `tag = "v0.17.0"`. One change an app may need: `fastframe_update::Release` has a new public field, so code that builds one by hand (a demo or a test) adds `published_at: None`. Code that only reads a `Release` needs nothing, and an app that doesn't use dates behaves exactly as before.

## New

- **A release says when it was published.** `Release::published_at` carries the listing's date, from GitHub and from an app's own feed. It is `None` when the listing doesn't say, as an older feed may not.
- **Every release on the channel, not only the newest.** `Updater::releases` lists every published release this build's channel accepts, newest first, older ones too, on stable builds as well.
- **A person can be given a release's download.** `Updater::download_link` gives the address of a release's download for this copy, for someone to open by hand.
- **A kept download remembers its date.** `Prepared::published_at` says when the release `Updater::kept` found came out. A download kept by an earlier version has none, and older versions ignore the new field in `staged.json`.
