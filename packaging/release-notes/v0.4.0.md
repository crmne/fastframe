fastframe 0.4.0 adds three crates the apps shared as copies:
- `fastframe-scroll` makes scrolling feel like the platform's, with a faster wheel and Linux touchpads that glide.
- `fastframe-instance` keeps one running copy per user.
- `fastframe-now-playing` puts what is playing, with its cover, in the desktop's media controls on Linux, Windows and macOS.

The tray can also start before the panel at login, grey out entries, and change its icon and tooltip.

Upgrade by moving the tag on every fastframe crate:

```toml
fastframe-tray = { git = "https://github.com/crmne/fastframe", tag = "v0.4.0" }
```

An app using `fastframe-tray` changes two things:

- **Add the new `Config` fields.** `themed_icon: true` and `menu_on_click: false` keep today's behaviour.
- **Ask `Tray::is_shown()` before keeping the app running on close.** On Linux, `spawn` no longer returns `None` when no panel is up, so checking for `Some` is no longer enough.

## New

- **Scrolling feels like the platform's (`fastframe-scroll`).** A wheel notch scrolls 120 points instead of egui's 40, unless the app set its own step. On Linux, touchpad gestures go 1.8 times further and glide on after the fingers lift, as on macOS. Fingers that rest before lifting do not fling the page. A gesture holds the axis it started on, and Shift turns it sideways, glide included. `stop()` hands scrolling over to something like middle-click autoscroll. It merges Spotifast's and ZapFast's copies, with the fixes each had made on its own. By @crmne.
- **One running copy per user (`fastframe-instance`).** The running copy holds a lock that the system releases even after a crash, so two launches at the same moment still make one. A second launch hands its request to the running copy and exits: show the window, open a link, or any line the app understands, with a reply such as a now-playing snapshot. The channel is a private socket on Unix, and a loopback port that needs a random token on Windows. A demo can run beside the real app in its own slot. It is ZapFast's guard, with the requests Spotifast's remote control needs. By @crmne.
- **What is playing, everywhere the desktop shows it (`fastframe-now-playing`).** The crate covers three places:
  - **Linux:** MPRIS, for the panel's player widget, `playerctl` and KDE Connect.
  - **Windows:** the media overlay.
  - **macOS:** the Now Playing panel and Control Centre.

  Each shows the title, artists, album, length and cover. The media keys, headset buttons and those panels send play, pause, next, previous, seek, volume, shuffle, repeat, open, raise and quit back. The cover is a file on disk, which every platform shows. It is Spotifast's media controls for all three platforms, with the extra details Solco publishes (genres, BPM, rating), and it brings artwork to apps that never sent any. By @crmne.
- **The tray starts before the panel at login.** On Linux, an app started at login could beat the panel and lose its tray for the session. The item now registers anyway and appears once a panel is up. `Tray::is_shown()` says whether one shows it, which stays false on a desktop without a tray, such as stock GNOME. By @crmne.
- **Tray entries can be greyed out, and the icon and tooltip can change.** This covers status lines, a dimmed icon while offline, and a tooltip with a detail line. `Config::themed_icon` stops naming the app icon on Linux, for a tray icon that is its own glyph. `Config::menu_on_click` opens the macOS menu on any click. By @crmne.

## Fixed

- **Underscores in Linux tray labels show as written.** DBusMenu read `_` as a keyboard-shortcut marker and dropped it, so names like `q3_plan.md` lost theirs. By @crmne.

## Known limitations

- **The macOS Now Playing panel and media keys have not been watched working yet.** The crate's tests pass on macOS. On Linux, MPRIS was driven on a private session bus. On Windows, the overlay was read back through the system's media session API, and its play/pause reached the app.
- **On Windows and macOS, the media controls show the title, artists, album, length and cover only.** Genres, BPM, rating, volume, shuffle and repeat appear on Linux alone.
- **`Config::menu_on_click` applies on macOS only.** A left click still shows the window on Windows and toggles it on Linux.
