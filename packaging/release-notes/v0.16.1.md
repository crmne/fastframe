fastframe 0.16.1 shares the rules for updates that install themselves, so every app can keep people on a supported version the way Solco does.

Move every fastframe crate to `tag = "v0.16.1"`. Apps need no code changes. An app that wants updates to install themselves calls the new `fastframe_update::policy`.

## New

- **Updates can install themselves, by Solco's rules.** `policy::offer` decides how a newer release reaches a copy: `Offer::Automatic` for a release on the same major version while the app's setting is on, `Offer::Ask` for a new major version, the setting off, or a person who went back to an older version on purpose, and `Offer::Elsewhere` for a copy that can't replace itself. `policy::may_download` downloads only while nothing the app does would be disturbed, and `policy::installs_at_start` says whether the update `Updater::kept` returns installs at the next start, before anything opens. `policy::newest_run` keeps the newest version that ran, so a person who went back isn't updated past it. What "nothing would be disturbed" means stays the app's. Moved from Solco (its ADR 0343). (#69)
