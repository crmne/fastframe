## Technical check (live site, 2026-11-13)

What's right: http and www redirect to `https://fastframe.dev/`; every sitemap URL answers 200 with one h1, a self-referencing canonical, a description, Open Graph and Twitter tags, and JSON-LD that parses (WebSite, WebPage, Person, BreadcrumbList, TechArticle). `robots.txt` names the sitemaps. No broken internal links; every page has 26 or more internal links in.

What was wrong, and what this pass did:

| Issue | Done |
|---|---|
| Homepage title was the one word "fastframe" (9 characters) | `seo.title` in `docs/index.md`, from the hero's own words |
| `/fastframe-macos/` answers 404, and Google still shows it (for "macos double click title bar to maximize") | A redirect page to `/fastframe-titlebar/` (`docs/fastframe-macos.html`), noindex and out of the sitemap |
| `/moving-apps/`'s description was the whole first paragraph of MIGRATION.md (291 characters) | Generated descriptions keep only the whole sentences that fit 160 characters (`FastframeDocs::Sources.fit`) |

**When it shows:** the docs at `/` are built from the newest release tag and `main` goes to `/next/` (jekyll-vitepress-theme 1.12.0). These changes appear at `/next/` when pushed and at `/` with the next fastframe release.

Left as proposals:

- **`/next/` is indexable and self-canonical**, and `robots.txt` lists `/next/sitemap.xml`, so every page exists twice. Google picks the root copies today (Search Console shows no `/next/` URL), but it splits signals. Fix in jekyll-vitepress-theme: non-stable versions get `noindex,follow` (or a canonical to the stable page when it exists) and stay out of `robots.txt`. That changes every site on the theme, so it's Carmine's call.
- **The social image is an SVG** (`/assets/images/logo.svg`). X, LinkedIn, Facebook and Slack don't render SVG previews. A 1200x630 PNG card (like native-packages' launch poster) would fix every shared link.
- `/fastframe-audio/`'s description (from the README's crate table) is 174 characters, one sentence; shorten the table row if wanted.
- Crate page titles are "fastframe-x | fastframe", which nobody searches. See "rust notifications" above.
